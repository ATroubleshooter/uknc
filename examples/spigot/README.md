# spigot — цифры π

Считает десятичные цифры π «кранным» алгоритмом (spigot) — целочисленной
арифметикой, без плавающих, выдавая цифры порциями по четыре по мере
вычисления. По умолчанию 1500 цифр; сколько считать, можно передать
параметром в командной строке RT-11 (`RUN SPIGOT 500`) — её разбирает
`parse_args` из crt0, так что `argc`/`argv` в `main` настоящие.

## Сборка и запуск

```bash
make                            # spigot.sav и spigot.dsk
make spigot.elf
../../gcc/dejagnu/uknc-run spigot.sav
```

## Что в нём смотреть

Это пример про память, а не про математику. Из 64 КБ адресного пространства
программа занимает около 14 КБ, стек crt0 ставит под самый верх свободной
памяти (`.SETTOP`), и всё, что между ними, делят стек и куча — без защитной
страницы, так что переполнение массива тихо затирает код самой программы.
Отсюда два решения, которые видно в исходнике:

- `r[]` — массив на стеке, 1500 коротких слов (3002 байта); `MAX_N` подобран
  так, чтобы запас оставался заметным;
- вывод идёт через `fputs` и собственный `ltoa`, а не через `printf`: на этой
  цели `printf` всегда тянет за собой `dtoa`/`mprec` — машинерию
  форматирования плавающих, — потому что `_printf_float` должен был бы быть
  слабым символом, а pdp11-бэкенд gcc слабых объявлений не поддерживает, и
  ссылка остаётся сильной независимо от того, встречается ли в программе
  `%f`. Плюс `setvbuf(stdout, NULL, _IONBF, 0)`: иначе первый же вывод
  выделит под буфер `BUFSIZ` — ещё 1024 байта.
