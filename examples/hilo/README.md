# hilo — угадай число

Игра в консоли: программа загадывает число от 0 до 99, принимает попытки со
стандартного ввода и отвечает «выше»/«ниже», пока не угадаешь, потом
предлагает сыграть ещё.

## Сборка и запуск

```bash
make                            # hilo.sav и hilo.dsk
make hilo.elf
```

`uknc-run` для этого примера не годится — он ничего не вводит, а программа
ждёт ответа. Запускать в эмуляторе с экраном и клавиатурой:

```bash
../../debugger/bin/ukncbtldebug --disk1 hilo.dsk \
    --rom ../../rom/uknc_rom_autoboot.bin --boot --screen
```

и в RT-11 — `RUN HILO`.

## Что в нём смотреть

Единственный пример с настоящим интерактивным вводом через стандартную
библиотеку: `fgets` со `stdin`, `printf` с `fflush`, `rand`, `atoi`, `strchr`,
`strcpy`. Клавиатуру читает штатная консоль RT-11 (`.TTYIN` через порт
newlib), перевод строки на входе порт приводит к `\n` сам, так что `fgets`
ведёт себя как на любой другой машине.

Буферизованный вывод здесь не мешает: программа не делает файловых операций —
ограничение, из-за которого остальные примеры обходятся `write()`, её не
касается.
