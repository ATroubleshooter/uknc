# macro11mix — половина на C, половина на MACRO-11

Программа, у которой две половины написаны на разных языках и отлаживаются
одинаково. На C — `main`, вывод и функция `SHOWWD`; на MACRO-11 — две
подпрограммы, таблица и место под её копию.

## Сборка и запуск

```bash
make                            # mix.sav, macro11mix.dsk и macro11mix.elf
../../gcc/dejagnu/uknc-run mix.sav
```

На диске `MIX.SAV`, а не `macro11mix.sav`: имя в RT-11 — шесть символов и три.
ELF собирается сразу вместе с образом, а не отдельной целью, как в остальных
примерах: символы здесь — половина смысла.

Вывод:

```
MIXTAB holds 8 words:
  000001
  000002
  ...
their checksum is 125554
one word more in the copy: 125555
```

## Что на какой стороне

`CSUM16` (в `mixasm.mac`) складывает слова с переносом через `ADC` — к биту
переноса из C не дотянуться, и это повод написать подпрограмму на ассемблере.
`EACHWD` обходит таблицу и на каждое слово вызывает `SHOWWD`, которая написана
на C, — так стык пересекается в обе стороны. Таблица `MIXTAB` лежит в
ассемблерном p-sect'е, а место под её копию — там же в `.BLKW`, и заполняет
его код на C.

Соглашение о вызове — то, которому подчиняется сам компилятор: аргументы на
стеке справа налево (первый на входе в `2(SP)`), снимает их вызывающий,
результат в `R0`, `R0`/`R1` свободны, `R2`–`R5` надо вернуть как были.

Имена, общие с ассемблером, ограничены RADIX-50: шесть символов, прописные.
Поэтому в C они объявлены через `__asm__("CSUM16")` — иначе компилятор попросит
у линкера `_csum16`, чего RADIX-50 не умеет записать вовсе.

## Символы и строки

`.mac` собирается `macro11` с ключом `-elf`: рядом с объектным модулем RT-11
появляется ELF-файл, в котором нет ничего кроме DWARF — номеров строк и
символов модуля (объектному модулю их хранить негде). Оба файла идут на строку
линковки, и дальше любой адрес программы, в какой бы половине он ни был, имеет
имя и строку исходника:

```bash
pdp11-uknc-rt11-nm macro11mix.elf | grep CSUM16        # где она оказалась
pdp11-uknc-rt11-addr2line -e macro11mix.elf <адрес>    # mixasm.mac:37
pdp11-uknc-rt11-gdb -batch -ex 'info line *&LOOP' macro11mix.elf
```

В gdb точка останова ставится по строке `.mac`, `step` идёт по ассемблерным
строкам, а `bt` показывает кадр ассемблерной подпрограммы:

```
#0  SHOWWD (word=1) at macro11mix.c:47
#1  EACHWD () at mixasm.mac:61
```

Дальше `main` раскрутка не идёт: у рукописного кода нет CFI, разворачивать
стек gdb нечем.
