# ansi — настоящая программа чужими руками

Утилита, переписывающая определения функций в C-исходнике: из K&R в ANSI
(по умолчанию), обратно (`-k`) или в набор прототипов (`-p`).

```
ansi [-k -p] <in.c> <out.c>
```

Своего кода проекта здесь нет: это `ansi` V1.7 (1991) Эндрю Мартина,
SciTech Software, — около 1250 строк C того времени, взятых как есть. Тем она
и интересна: программа заметного размера, написанная задолго до этого
тулчейна и не под него, собирается и работает на машине без правок.
Лицензия — в заголовке `ansi.c`: копировать и распространяться бесплатно
можно, продавать без разрешения автора нельзя, правки надо помечать.

## Сборка и запуск

```bash
make                            # ansi.sav и ansi.dsk
```

Программе нужны файлы, так что запускать её имеет смысл на образе диска, куда
положен исходник для обработки:

```bash
rt11dsk a ansi.dsk IN.C
../../debugger/bin/ukncbtldebug --disk1 ansi.dsk \
    --rom ../../rom/uknc_rom_autoboot.bin --boot --screen
```

и в RT-11 — `RUN ANSI IN.C OUT.C`. Имена файлов — по правилам RT-11: шесть
символов и три.

## Что в нём смотреть

Как ведёт себя на этой цели обычный код: `malloc`, `fopen`/`fgets`/`fputs`,
`strcpy`, `isalpha`, разбор аргументов командной строки. Из всех примеров
только у этого сборка без `-ffunction-sections`/`-fdata-sections` и без цели
`.elf`: он собирается и так, и лишнего про него сказать нечего.
