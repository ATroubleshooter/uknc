# ppurun — запустить код на втором процессоре

Самый маленький пример работы с ПП. ЦПУ-часть (`ppurun.c`) читает с диска
модуль `PPTEST.PPU`, раскладывает его в памяти периферийного процессора и
запускает; ПП-часть (`pptest.c`) печатает ` PPU IS ALIVE` через EMT 056
резидентного отладочного монитора ПП — то есть на его собственный экран, а не
в консоль RT-11.

## Сборка и запуск

```bash
make                            # ppurun.sav, pptest.ppu и ppurun.dsk
make ppurun.elf                 # с символами, для gdb (и pptest.ppu.elf рядом)
```

`uknc-run` здесь не подходит: он кладёт на свежий образ одну только `.sav`, а
программе нужен рядом файл `PPTEST.PPU`. Запускать с образа примера:

```bash
../../debugger/bin/ukncbtldebug --disk1 ppurun.dsk \
    --rom ../../rom/uknc_rom_autoboot.bin --boot --screen
```

и в RT-11 — `RUN PPURUN`.

## Что в нём смотреть

- `ppuc_load_code()`/`ppuc_run()` из `ppu_client.h`: загрузчик сам разбирает
  блоки GSD/TXT/RLD/ENDMOD объектного модуля RT-11, раскладывает
  `.text`/`.data`/`.bss` по памяти ПП, применяет релокации и возвращает адрес
  загрузки, он же точка входа.
- `ppu_main()` в `pptest.c` — точка входа ПП-программы; шим `libppu`
  (`ppus_start.c`) вызывает её, а по возврату сам освобождает память модуля и
  отдаёт управление резидентному монитору ПП.
- Сборка ПП-части — своим линкером `pdp11-uknc-rt11-ld-ppu`: он уже несёт в
  себе `ppu.ld` (гарантирует, что `START` окажется по смещению 0) и линковку с
  `libppu.a`. Имя на диске — `PPTEST.PPU`, шесть символов и три.
- Подробности библиотеки — в `libs/libppu/ppu_client.h` и `ppu_server.h` и в
  разделе про libppu в README проекта.
